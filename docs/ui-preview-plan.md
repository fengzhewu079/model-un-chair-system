## 设计与验收
- 保留蓝白、顶部阶段/房间/成员状态和左侧完成记录的使用逻辑。采用细线、清楚排版与会议议程的序号，避免套卡片/巨型空态/装饰渐变。
- 首页与建会减少重复说明，表单首屏优先；原有FAQ、演示、创建、加入保留。
- 动议默认用明确单位的独立时间字段；保留可选10/60快捷输入。输入后立即计算，无Confirm弹窗。单条一键保存；多条“添加另一条动议”后统一保存，最多四条；结束录入后照旧进入待投票列表，保留投票规则。
- 所有原动议类型保留。时间非有限、非正、单人超过总时长须拦截；向下取整的发言席位数和实际时长明确显示，数据格式兼容旧版。
- 设置按偏好/房间/记录分开，成功导出不弹阻塞框，重置仍确认。
- 手机和桌面主流程可用；键盘焦点与字段标签清楚，减少动画并尊重reduced-motion。
